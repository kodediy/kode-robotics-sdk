robotics
========

The standard layer: the calls an app makes from its own tasks, all in robotics.h. Each waits for the owner's verdict and answers true or false. robotics_aos, robotics_drv and robotics_bsp come with it; an app with an Active Object names robotics_sys instead, or as well.

Depends on: robotics_aos, robotics_bsp, and kdefs from kode-sdk

Docs: https://docs.kode.diy/modules/robotics
