robotics_aos
============

The owner of the module: one Active Object and its worker. It finds the module, upright or turned round, and is the only code that drives it; every call of the two layers asks it.

Depends on: robotics_drv, robotics_bsp, and kode, kode_sys and kdefs from kode-sdk

Docs: https://docs.kode.diy/modules/robotics
